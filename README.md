# KORSHUN Zapret

Удобный графический интерфейс для управления **zapret** — утилитой для тонкой настройки сетевых соединений на Windows.

Проект представляет собой GUI-обёртку, которая упрощает работу с оригинальным zapret: выбор стратегий, запуск, установка службы, тестирование — всё в одном окне, без ручного редактирования `.bat`-файлов и командной строки.


---

## ✨ Возможности

- 🎛 **Удобный выбор стратегий** — список всех доступных `.bat`-конфигураций из папки zapret.
- ✅ **Два режима запуска:**
  - **Одноразовый** — запуск выбранной стратегии вручную через кнопку.
  - **Долгий (служба Windows)** — установка стратегии как системной службы, работает автоматически и после перезагрузки.
- 🧪 **Тестирование стратегий** — быстрый доступ к встроенным тестам zapret (Run Tests / DPI Checkers) для подбора оптимальной конфигурации под вашего провайдера.
- 📦 **Установка и удаление службы** — прямо из интерфейса, без ручного запуска `service.bat`.
- 🔔 **Системный трей** — программа сворачивается в трей и продолжает работать в фоне.
- ⚙️ **Гибкая настройка пути** — путь к папке zapret выбирается через диалог и сохраняется в конфиг.
- 🚀 **Автозапрос прав администратора** — при запуске программа сама запрашивает повышенные права, необходимые для работы zapret.

## 📥 Установка

### 1. Готовая сборка

1. Перейди в раздел [**Releases**](../../releases).
2. Скачай последний ZIP-архив (`KORSHUNZapret.zip`).
3. Распакуй архив в удобное место (например, `C:\KORSHUNZapret`).
4. Запусти `KORSHUNZapret.exe`.

### 2. Рекомендуемая версия zapret

Для корректной работы рекомендуется использовать **zapret версии 1.10.3** от Flowseal:

📥 [Скачать zapret 1.10.3](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3)

## 🚀 Использование

1. При первом запуске программа попросит указать **путь к папке с zapret** (например, `C:\KORSHUNzapret`).
   - ⚠️ Путь **не должен содержать пробелов и кириллицы**.
2. Выбери нужную **стратегию** из выпадающего списка.
3. Выбери **режим запуска**:
   - **Одноразовый** — просто нажми «Включить обход».
   - **Долгий** — нажми «Установить службу» и следуй инструкциям в открывшемся окне.
4. Для подбора лучшей стратегии под твоего провайдера используй кнопку **«🧪 Тест стратегий»**.

## ⚠️ Важно

### Антивирус

Windows Defender и сторонние антивирусы могут ругаться на файлы `winws.exe` и `WinDivert64.sys`, которые входят в состав zapret. Это **ложное срабатывание** — данные файлы являются легитимными компонентами open-source инструмента zapret и используются для работы с сетевыми драйверами.

**Решение:** добавь папку с zapret и папку с KORSHUN Zapret в исключения антивируса.

### Права администратора

Zapret требует прав администратора для корректной работы. Программа автоматически запрашивает их при запуске — подтверди UAC-запрос.
